# Bản vá trùng cổng Cover Studio

[Tải ZIP bản vá](https://github.com/vn8690-create/Karaoke_Sub/raw/refs/heads/main/downloads/Karaoke_Sub-sua-trung-cong.zip).

Dừng cửa sổ START của Karaoke Sub, giải nén đè vào thư mục Karaoke_Sub hiện có (ngang hàng `local_studio` và `windows`), rồi chạy lại `windows\START.bat`. Không cần chạy SETUP hoặc tắt Cover Studio.

Mặc định mới là `http://127.0.0.1:8776`; nếu bận, app tự chọn cổng khác và in địa chỉ thực. Bản vá chỉ thay bốn file mã nguồn và kèm giấy phép/hướng dẫn; không chứa model, thư viện hoặc dữ liệu dự án.
