# Bản cập nhật mới nhất: lời chuẩn và video nền

[Tải ZIP cập nhật đầy đủ phần local](https://github.com/vn8690-create/Karaoke_Sub/raw/refs/heads/main/downloads/Karaoke_Sub-cap-nhat-toi-uu.zip).

Dừng START → giải nén đè vào thư mục Karaoke_Sub hiện có → chạy **windows\UPDATE.bat** một lần → START → **Ctrl+F5**. UPDATE thêm thư viện căn lời chuẩn vào môi trường hiện có; không ép cài lại PyTorch, không thay dự án/model.

Có TXT/dán lời để căn theo giọng hát, dịch thời gian toàn bài, font/màu/vị trí/lề, chọn nền từ thư mục hoặc Commons/Pexels. [Hướng dẫn sử dụng](../docs/LOCAL-USAGE.md). Pexels cần key; Commons dùng được không cần key.

Các gói cũ phía dưới chỉ giữ để tham khảo, không có toàn bộ chức năng mới.

# Cập nhật Karaoke Sub

## Thêm mục Hướng dẫn sử dụng

[Tải ZIP cập nhật hướng dẫn](https://github.com/vn8690-create/Karaoke_Sub/raw/refs/heads/main/downloads/Karaoke_Sub-cap-nhat-huong-dan.zip). Gói này kèm cả bản sửa trùng cổng.

Dừng START, giải nén đè vào thư mục Karaoke_Sub đang dùng, chạy lại `windows\START.bat`, rồi nhấn **Ctrl+F5** trong trình duyệt. Nhấn **Hướng dẫn** ở góc trên; khi chưa có dự án, hướng dẫn tự hiện. Không cần SETUP lại, không thay thư viện/model/dự án.

Đọc [hướng dẫn chi tiết](../docs/LOCAL-USAGE.md).

## Chỉ sửa trùng cổng Cover Studio

[Tải ZIP bản vá](https://github.com/vn8690-create/Karaoke_Sub/raw/refs/heads/main/downloads/Karaoke_Sub-sua-trung-cong.zip).

Dừng cửa sổ START của Karaoke Sub, giải nén đè vào thư mục Karaoke_Sub hiện có (ngang hàng `local_studio` và `windows`), rồi chạy lại `windows\START.bat`. Không cần chạy SETUP hoặc tắt Cover Studio.

Mặc định mới là `http://127.0.0.1:8776`; nếu bận, app tự chọn cổng khác và in địa chỉ thực. Bản vá chỉ thay bốn file mã nguồn và kèm giấy phép/hướng dẫn; không chứa model, thư viện hoặc dữ liệu dự án.
